### What I Do Best
- **Feature Engineering & Signal Extraction:** Constructing domain-informed features from raw behavioral, 
  telemetry, and demographic data that consistently outperform naive baselines.
- **Ensemble Learning Architecture:** Designing multi-framework blending and meta-learning stacking 
  classifiers (LightGBM, XGBoost, HistGradientBoosting).
- **Robust Validation Engineering:** Enforcing Stratified K-Fold cross-validation to map probability 
  distributions precisely and prevent out-of-fold data leakage.
- **Class Imbalance Handling:** Managing heavily skewed targets (up to 82/18 ratio) using 
  class weighting and stratified sampling strategies.
